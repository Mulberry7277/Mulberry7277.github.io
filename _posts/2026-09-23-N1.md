# 果蝇全脑连接组启发的新一代人工神经网络：从 Connectome 到可运行 ANN/SNN

这个方向近两三年已经从“神经科学给 AI 一点灵感”，进入了更具体的阶段：

> **直接把真实神经系统的连接拓扑、兴奋/抑制符号、时间动力学、空间约束甚至感觉—运动接口，变成人工网络的结构先验。**

一个最重要的基本认识是：

> **Connectome 本身不是一个可以运行的神经网络。**

它主要告诉我们（在具体数据版本和质控阈值下）：

- 谁连接谁；
- 连接多少；
- 在哪里连接；
- 部分神经递质身份；
- 神经元类型及解剖位置。

但要把 Connectome 变成可以执行任务的人工神经网络，还必须补上至少四层东西：

1. **节点动力学**
2. **突触符号与权重尺度**
3. **感觉输入编码**
4. **行为输出与学习规则**

目前几条最重要的技术路线可以粗略概括为：

- **Shiu et al., Nature 2024**
  固定 Connectome + 神经递质标签 → 全脑 LIF 计算模型；
- **Lappalainen et al., Nature 2024**
  固定视觉回路拓扑 → 可梯度训练的连续时间循环网络；
- **FlyGM 等 2026 工作**
  固定 Connectome 拓扑 → 具身强化学习策略网络（预印本）；

三者连起来，大体构成了：

```text
Connectome
    ↓
结构化神经动力学模型
    ↓
任务优化
    ↓
具身智能
```

# 2. 果蝇 Connectome 如何变成人工神经网络？

设原始 Connectome 为一个有向图：

$$
G=(V,E)
$$

一个神经元节点：

$$
v_i=
(
ID_i,\,
type_i,\,
NT_i,\,
position_i,\ldots
)
$$

一条聚合后的有向连接：

$$
e_{ij}
=
(
i,\,j,\,
c_{ij},\,
r_{ij},\ldots
)
$$

其中：

- \(i\)：presynaptic neuron；
- \(j\)：postsynaptic neuron；
- \(c_{ij}\)：两个神经元之间的聚合突触计数；
- \(r_{ij}\)：neuropil、神经递质、compartment 等辅助信息。

真正的转换流程可以写成：

```text
EM reconstruction
        ↓
biological neuron IDs
        ↓
node mapping
        ↓
directed sparse graph
        ↓
synapse sign + magnitude
        ↓
neuron dynamics
        ↓
sensory / motor interface
        ↓
trainable recurrent network
```

# 3. 第一步：Node Mapping

FlyWire 中神经元通常具有很大的 `root_id`。

例如：

```text
720575940612345678
720575940623456789
720575940634567890
```

这种 ID 不适合作为 PyTorch Tensor 的连续下标。

因此首先应该建立：

$$
\texttt{root\_id}
\rightarrow
0,1,2,\ldots,N-1
$$

例如：

```text
720575940612345678 → 0
720575940623456789 → 1
720575940634567890 → 2
```

代码：

```python
root_ids = nodes["root_id"].astype("int64").to_numpy()

id2idx = {
    int(root_id): i
    for i, root_id in enumerate(root_ids)
}
```

同时，应为每个节点保存生物学 metadata：

```python
node[i] = {
    "root_id": ...,
    "cell_type": ...,
    "super_class": ...,
    "flow": ...,
    "neurotransmitter": ...,
    "side": ...,
    "neuropil": ...
}
```

尤其重要的是：

```text
cell_type
super_class
flow
neurotransmitter
```

这样可以把所有节点分成：

$$
V=
V_\text{sensory}
\cup
V_\text{intrinsic}
\cup
V_\text{ascending}
\cup
V_\text{descending}
\cup
V_\text{motor}
\cup\cdots
$$

否则网络虽然可以计算，却不知道：

- 外界观察应该输入哪些节点；
- 哪些节点属于内部计算；
- 应该从哪些节点读取行为输出。

# 4. biological neuron 如何映射为 artificial node？

至少有三种方案。

## 4.1 一个 biological neuron 对应一个 artificial unit

最直接：

$$
\boxed{
1\ biological\ neuron
=
1\ artificial\ recurrent\ unit
}
$$

例如：

```text
FlyWire neuron 12345
        ↓
PyTorch hidden state h[78231]
```

这样最大的优点是：

**可解释性非常强。**

例如进行 lesion：

```python
h[:, 78231] = 0
```

或者直接删除该神经元的所有 incoming/outgoing edges。

Shiu 等人的 whole-brain model 最接近这种思路。

---

## 4.2 Cell-type aggregation

也可以把很多同类型神经元聚合：

$$
\{
\text{many biological neurons of type T}
\}
\rightarrow
\text{one artificial population}
$$

例如：

```text
139,000 neurons
        ↓
3,000–10,000 cell-type/population nodes
```

优点：

- 节省大量显存；
- 更容易训练；
- 更容易做大型 RL。

缺点：

会损失：

- individual neuron variability；
- left/right asymmetry；
- retinotopy；
- single-neuron recurrent loop；
- single-neuron lesion analysis。

---

# 5. 第三种方案：一个 biological neuron 对应多个计算 compartment

更激进的方法是：

$$
1\ biological\ neuron
\rightarrow
\text{multiple artificial compartments}
$$

例如：

```text
dendrite
   ↓
soma
   ↓
axon
```

或者：

$$
h_i=
(
h_i^{dendrite},
h_i^{soma},
h_i^{axon}
)
$$

这与真实神经元更接近。

Beniaguev 等人的工作表明，一个真实皮层锥体神经元的输入—输出动力学，可能需要相当复杂的时序模型才能逼近。

因此未来 ANN 中的基本单元可能不再只是：

$$
y=\operatorname{ReLU}(Wx+b)
$$

而是：

$$
(h_{t+1},y_t)
=
F_\theta(x_t,h_t)
$$

也就是说：

> 一个“人工神经元”本身就是一个小型 dynamical system。

# 6. 最关键问题：Synapse Count 如何变成 ANN Weight？

Connectome 通常不会直接告诉你经典神经网络中的：

$$
W_{ij}=0.731
$$

它首先告诉你的通常是：

$$
c_{ij}
=
\text{number of anatomical synapses}
$$

最直接的转换方式是：

$$
|W_{ij}|
\propto
c_{ij}
$$

在最简化的模型中，符号可由递质类别或受体信息近似决定；真实的兴奋/抑制效应还取决于受体与细胞状态。

定义：

$$
s_i=
\begin{cases}
+1,&\text{excitatory}\\
-1,&\text{inhibitory}
\end{cases}
$$

则：

$$
\boxed{
W_{ij}
=
s_i\,c_{ij}\,w_0
}
$$

其中：

- \(c_{ij}\)：synapse count；
- \(s_i\)：presynaptic neuron 的递质符号；
- \(w_0\)：unitary synapse strength。

例如：

```text
Neuron A → Neuron B
synapse count = 12
A = excitatory
```

则：

$$
W_{AB}=+12w_0
$$

如果 A 是 inhibitory：

$$
W_{AB}=-12w_0
$$

# 7. Shiu 型全脑模型中的权重

Shiu 等人的 whole-brain LIF 模型中，思想可以概括为：

$$
W_{ij}
=
n_{ij}
\times
sign_i
\times
w_\text{syn}
$$

其中：

$$
w_\text{syn}
\approx
0.275\ {\rm mV}
$$

即：

```text
anatomical synapse number
        ×
excitatory/inhibitory sign
        ×
unitary PSP amplitude
```

形成真正可运行的全脑 spiking network。

这里的科学问题不是：

> 怎样获得最高 benchmark accuracy？

而是：

> 仅仅根据真实 wiring diagram 和 neurotransmitter identity，能否预测感觉刺激之后哪些 downstream neurons 会被激活？

这与传统 ANN 的目标很不同。

# 8. 为什么不能总是直接使用 Synapse Count？

例如：

```text
A → B : 3 synapses
A → C : 300 synapses
```

如果直接设：

```text
W_AB = 3
W_AC = 300
```

权重 dynamic range 会非常大。

高度连接 hub 还可能让 recurrent activity 很容易爆炸。

因此如果目标是机器学习，而不是严格模拟 electrophysiology，通常可以定义一个：

$$
\tilde c_{ij}=f(c_{ij})
$$

例如：

## 8.1 Raw count

$$
f(c)=c
$$

最忠于 anatomy。

---

## 8.2 Log scaling

$$
f(c)=\log(1+c)
$$

适合压缩 long-tail distribution。

---

## 8.3 Postsynaptic normalization

$$
\tilde c_{ij}
=
\frac{c_{ij}}
{\sum_k c_{kj}}
$$

含义：

> 这条连接占 postsynaptic neuron 总输入的比例。

---

## 8.4 Degree normalization

类似 GNN：

$$
\tilde c_{ij}
=
\frac{c_{ij}}
{\sqrt{
d_i^\text{out}
d_j^\text{in}
}}
$$

---

# 9. 更适合新 ANN 的权重形式

可以将真实权重定义成：

$$
\boxed{
W_{ij}
=
s_i
\tilde c_{ij}
\operatorname{softplus}
(
\alpha_{g(i,j)}
)
}
$$

其中：

$$
g(i,j)
$$

可以表示：

```text
pre cell type
+
post cell type
+
neuropil
+
synapse class
```

例如：

```text
cholinergic projection neuron
        ↓
Kenyon cell
```

所有这种类型的连接共享一个参数：

$$
\alpha_{\text{PN→KC}}
$$

而不是每一条 edge 都单独训练。

因此：

```text
Connectome
决定：
    有没有边

Neurotransmitter
决定：
    正负号

Synapse count
决定：
    结构相对强弱

Gradient descent
决定：
    某一类突触的生理增益
```

这就是非常重要的：

$$
\boxed{
\text{freeze anatomy, learn physiology}
}
$$

# 10. 为什么参数共享很重要？

假设网络有：

```text
1,500,000 edges
```

传统 ANN 可能有：

```text
1,500,000 independent trainable weights
```

但 biological network 不一定需要如此。

可以把大量连接共享成：

```text
cell type A → cell type B
```

的共同生理参数。

因此可能出现：

$$
1.5\ million\ edges
$$

但只有：

$$
\sim10^3
$$

甚至几百个真正自由的生理参数。

Lappalainen 等人的 connectome-constrained visual model 正体现了这种思路。

# 11. Dale's Law

普通 ANN 中一个 neuron 可以具有：

```text
→ +0.8
→ -1.2
→ +0.3
→ -0.6
```

也就是说：

> 同一个 neuron 的不同输出边可以有不同正负号。

但生物系统中，大部分情况下更接近：

```text
Excitatory neuron:

→ +
→ +
→ +
→ +
```

或者：

```text
Inhibitory neuron:

→ -
→ -
→ -
→ -
```

因此不建议直接：

```python
W = nn.Parameter(
    torch.randn(E)
)
```

因为训练之后：

```text
excitatory edge
```

可能直接被 gradient descent 训练成：

```text
inhibitory edge
```

从而破坏最重要的 biological constraint。

更好的做法：

```python
magnitude = F.softplus(raw_gain)

weight = (
    sign
    * structural_strength
    * magnitude
)
```

由于：

$$
\operatorname{softplus}(x)>0
$$

所以：

$$
sign(W_{ij})
$$

永远不会被 gradient descent 改变。

即：

$$
\boxed{
\text{learn magnitude, freeze sign}
}
$$

# 12. Dopamine 等 Neuromodulator 不应该简单变成 ±1

快速作用的经典递质，例如：

- acetylcholine；
- GABA；
- glutamate。

在建模时可以先把它们近似为快速兴奋性或抑制性电流，但这种映射需要注明适用范围：果蝇脑内 ACh 通常按兴奋性处理，GABA 通常按抑制性处理，而 glutamate 可能随受体而异。

```text
fast excitatory current
```

或者：

```text
fast inhibitory current
```

相较之下，以下递质通常更适合作为调制信号，而不是简单的固定 ±1 符号：

- dopamine；
- serotonin；
- octopamine。

它们更适合作为：

$$
m(t)
$$

这样的 modulation signal。

例如：

$$
W_{ij}^{eff}(t)
=
W_{ij}
\left(
1+\beta_{ij}m(t)
\right)
$$

即：

> 同一条 synapse 的有效强度会随全局或局部调制状态改变。

更进一步，可以用于 three-factor learning：

$$
\Delta W_{ij}
=
\eta
e_{ij}(t)
m(t)
$$

其中：

- \(e_{ij}(t)\)：local eligibility trace；
- \(m(t)\)：dopamine/reward signal；
- \(\eta\)：learning rate。

这样：

```text
pre/post neural activity
        ↓
eligibility trace
        ↓
dopamine/reward
        ↓
plasticity
```

这与 reinforcement learning 可以非常自然地连接。

# 13. FlyWire 数据转换为 PyTorch Sparse Graph

假设整理得到：

```text
nodes.csv

root_id
cell_type
flow
super_class
neurotransmitter
```

以及：

```text
edges.parquet

pre_id
post_id
syn_count
nt_type
```

一个基本转换程序可以写成：

```python
import numpy as np
import pandas as pd
import torch


nodes = pd.read_csv("nodes.csv")
edges = pd.read_parquet("edges.parquet")


# ==================================================
# 1. Biological root_id -> contiguous tensor index
# ==================================================

root_ids = nodes["root_id"].astype("int64").to_numpy()

id2idx = {
    int(root_id): i
    for i, root_id in enumerate(root_ids)
}


# ==================================================
# 2. Remove edges whose nodes are missing
# ==================================================

edges = edges[
    edges["pre_id"].isin(id2idx.keys())
    & edges["post_id"].isin(id2idx.keys())
].copy()


edges["src"] = (
    edges["pre_id"]
    .map(id2idx)
    .astype(np.int64)
)

edges["dst"] = (
    edges["post_id"]
    .map(id2idx)
    .astype(np.int64)
)


# ==================================================
# 3. Aggregate anatomical synapses
# ==================================================
# nt_type should describe the presynaptic transmitter class.
# If the source table stores synapses at row level, aggregate by
# (src, dst, nt_type) and resolve conflicting labels upstream.

edges = (
    edges
    .groupby(
        ["src", "dst", "nt_type"],
        as_index=False
    )
    ["syn_count"]
    .sum()
)


# ==================================================
# 4. Neurotransmitter sign
# ==================================================

def nt_sign(nt, fixed_lif=True):
    """Return a model-specific sign approximation.

    With fixed_lif=True this follows the coarse convention used by
    Shiu et al. for a runnable LIF baseline. For a mechanistic model,
    set fixed_lif=False and route modulators/receptor information
    through a separate pathway instead of deleting those edges.
    """
    nt = str(nt).lower()

    if "acetylcholine" in nt or nt in {"ach", "cholinergic"}:
        return +1.0
    if "gaba" in nt:
        return -1.0
    if "glut" in nt:
        return -1.0 if fixed_lif else 0.0
    if any(name in nt for name in ("dopamine", "serotonin", "octopamine", "histamine")):
        return +1.0 if fixed_lif else 0.0
    return 0.0

edges["sign"] = edges["nt_type"].map(nt_sign)


# ==================================================
# 5. Structural magnitude
# ==================================================

count = (
    edges["syn_count"]
    .to_numpy(np.float32)
)

structural_mag = np.log1p(count)

edges["base_weight"] = (
    edges["sign"].to_numpy(np.float32)
    * structural_mag
)


# ==================================================
# 6. Convert to PyTorch tensors
# ==================================================

src = torch.tensor(
    edges["src"].to_numpy(),
    dtype=torch.long
)

dst = torch.tensor(
    edges["dst"].to_numpy(),
    dtype=torch.long
)

base_weight = torch.tensor(
    edges["base_weight"].to_numpy(),
    dtype=torch.float32
)


N = len(nodes)
E = len(edges)

print("neurons =", N)
print("edges   =", E)
```

至此完成：

```text
EM reconstruction
       ↓
biological IDs
       ↓
integer indices
       ↓
directed sparse graph
       ↓
signed structural weights
```

# 14. 为什么一定要使用 Sparse Graph？

假设：

$$
N=139255\quad(\text{以 FlyWire v783 为例})
$$

如果建立完整 dense matrix：

$$
W\in\mathbb{R}^{139255\times139255}
$$

元素数量大约为：

$$
139255^2
\approx
1.94\times10^{10}
$$

如果是 float32：

$$
1.94\times10^{10}
\times
4
\approx
77.6\ {\rm GB}
$$

这还没有包括：

- gradient；
- optimizer state；
- recurrent activation；
- temporal BPTT memory。

因此正确表示方式不是：

```python
W = torch.zeros(
    139255,
    139255
)
```

而是 edge list：

```text
src
dst
weight
```

例如：

```python
src = [3, 3, 10, 21, ...]
dst = [8, 9, 11, 30, ...]
w   = [...]
```

复杂度主要与：

$$
E
$$

而不是：

$$
N^2
$$

相关。

# 15. Connectome-Constrained RNN

连续时间 dynamics 可以写成：

$$
\tau_i
\frac{dh_i}{dt}
=
-h_i
+
\phi
\left(
\sum_jW_{ji}h_j
+
I_i(t)
+
b_i
\right)
$$

使用 Euler method：

$$
h_i^{t+1}
=
h_i^t
+
\frac{\Delta t}{\tau_i}
\left[
-h_i^t
+
\phi(
I_i^t
)
\right]
$$

一个 PyTorch 实现如下：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class ConnectomeRNN(nn.Module):

    def __init__(
        self,
        n_nodes,
        src,
        dst,
        base_weight,
        sensor_idx,
        output_idx,
        obs_dim,
        action_dim,
        edge_group=None,
        n_edge_groups=None,
        dt=0.01,
    ):

        super().__init__()

        self.n_nodes = n_nodes
        self.dt = dt


        # ============================================
        # Connectome structure
        # ============================================

        self.register_buffer(
            "src",
            src
        )

        self.register_buffer(
            "dst",
            dst
        )

        self.register_buffer(
            "base_weight",
            base_weight
        )


        # ============================================
        # Biological input / output neuron sets
        # ============================================

        self.register_buffer(
            "sensor_idx",
            torch.as_tensor(
                sensor_idx,
                dtype=torch.long
            )
        )

        self.register_buffer(
            "output_idx",
            torch.as_tensor(
                output_idx,
                dtype=torch.long
            )
        )


        # ============================================
        # Edge-group parameter sharing
        # ============================================

        if edge_group is None:
            edge_group = torch.zeros_like(src)
            n_edge_groups = 1
        else:
            edge_group = torch.as_tensor(edge_group, dtype=torch.long)
            if n_edge_groups is None:
                n_edge_groups = int(edge_group.max().item()) + 1

        self.register_buffer("edge_group", edge_group)
        self.raw_gain = nn.Parameter(torch.zeros(n_edge_groups))


        # ============================================
        # Environment observation -> sensory neurons
        # ============================================

        self.encoder = nn.Linear(
            obs_dim,
            len(sensor_idx)
        )


        # ============================================
        # Biological output neurons -> action
        # ============================================

        self.decoder = nn.Linear(
            len(output_idx),
            action_dim
        )


        # ============================================
        # Simplified time constant
        # ============================================

        self.raw_tau = nn.Parameter(
            torch.tensor(0.0)
        )


    def effective_weight(self):

        gain = F.softplus(
            self.raw_gain
        )

        return (
            self.base_weight
            *
            gain[self.edge_group]
        )


    def step(
        self,
        obs,
        h
    ):

        w = self.effective_weight()


        # ============================================
        # Sparse message passing
        #
        # m_e = h_source * W_e
        # ============================================

        msg = (
            h[:, self.src]
            *
            w.unsqueeze(0)
        )


        recurrent_input = (
            torch.zeros_like(h)
        )


        # ============================================
        # Sum all messages arriving at each neuron
        # ============================================

        recurrent_input.index_add_(
            dim=1,
            index=self.dst,
            source=msg
        )


        # ============================================
        # External sensory current
        # ============================================

        external = h.new_zeros(h.shape)
        external = external.index_copy(
            1,
            self.sensor_idx,
            self.encoder(obs)
        )


        # ============================================
        # Positive time constant
        # ============================================

        tau = (
            0.005
            +
            F.softplus(
                self.raw_tau
            )
        )


        target = F.relu(
            recurrent_input
            +
            external
        )


        # ============================================
        # Euler integration
        # ============================================

        h = (
            h
            +
            self.dt / tau
            *
            (
                -h
                +
                target
            )
        )


        # ============================================
        # Read behavior from output population
        # ============================================

        action = self.decoder(
            h[:, self.output_idx]
        )


        return h, action


    def forward(
        self,
        obs_sequence
    ):

        B, T, _ = (
            obs_sequence.shape
        )


        h = torch.zeros(
            B,
            self.n_nodes,
            device=obs_sequence.device
        )


        outputs = []


        for t in range(T):

            h, y = self.step(
                obs_sequence[:, t],
                h
            )

            outputs.append(y)


        return torch.stack(
            outputs,
            dim=1
        )
```

这里需要区分两件事：`F.relu` 只是节点更新函数；真正决定循环层结构的是边上的消息传递：

```python
msg = (
    h[:, self.src]
    *
    w.unsqueeze(0)
)
```

以及：

```python
recurrent_input.index_add_(
    dim=1,
    index=self.dst,
    source=msg
)
```

它们实际上实现：

$$
m_{i\rightarrow j}
=
h_iW_{ij}
$$

然后：

$$
I_j
=
\sum_{i:i\rightarrow j}
m_{i\rightarrow j}
$$

因此，循环层的边结构由 Connectome 给出；输入编码器和输出解码器仍然是额外的接口参数。

这里没有：

```python
nn.Linear(
    139255,
    139255
)
```

这样的 dense recurrent layer。

# 16. Sensory Nodes 应该怎样选择？

不要简单做：

```python
input = Linear(
    camera,
    139255
)
```

然后直接刺激整个脑。

这样虽然 recurrent connectivity 仍然来自 Connectome，但 sensory interface 已经完全脱离 biology。

更合理的是：

$$
x(t)
\xrightarrow{
sensory\ encoder
}
V_\text{sensory}
$$

例如视觉：

```text
camera / visual field
        ↓
retinotopic encoder
        ↓
photoreceptor neurons
        ↓
lamina
        ↓
medulla
        ↓
lobula
        ↓
central brain
```

也就是说：

> 外界信息必须首先进入真正的 sensory population。

最粗略的写法：

```python
sensor_idx = nodes[
    nodes["flow"] == "afferent"
].index
```

但研究级项目应进一步按 modality 分类：

```text
visual

olfactory

gustatory

mechanosensory

auditory

proprioceptive
```

每种 modality 使用不同 encoder。

# 17. Output Nodes 也应该遵守生物结构

同样，不建议：

```python
action = Linear(
    h,
    6
```

直接从整个脑的所有 neuron activity 读取 action。

更合理的是：

$$
V_\text{brain}
\rightarrow
V_\text{descending}
\rightarrow
V_\text{motor}
\rightarrow
a_t
$$

例如：

```python
output_idx = nodes[
    nodes["super_class"].isin(
        [
            "descending",
            "motor"
        ]
    )
].index
```

于是模型结构是：

```text
environment
    ↓
sensory neurons
    ↓
internal connectome
    ↓
descending neurons
    ↓
motor system
    ↓
action
```

这比：

```text
environment
    ↓
MLP
    ↓
action
```

更接近真实 nervous system。

# 18. 三类 Connectome 模型

目前可以大致分成三类。

| 模型                       | Connectome    | 权重                                | 神经动力学              | 学习           | 主要目标                |
| -------------------------- | ------------- | ----------------------------------- | ----------------------- | -------------- | ----------------------- |
| Whole-brain LIF            | 固定          | synapse count × sign × fixed scale  | LIF                     | 基本不学习     | 模拟 biological circuit |
| Connectome-constrained DMN | 固定          | anatomy fixed，physiology trainable | continuous RNN          | BPTT           | 理解 neural computation |
| Connectome RL controller   | 固定 topology | dynamics/readout trainable          | message-passing RNN/GNN | imitation + RL | embodied control        |

如果目标是：

> “根据神经机制设计新一代 ANN”

那么第二、第三类通常比纯粹固定的 LIF simulation 更有工程意义。

# 19. Connectome-Constrained Task Optimization

一个很实用的设计是：

$$

=
s_i
c_{ij}
\alpha_{T_i,T_j}

固定：

```text
edge existence
synapse count
synaptic sign
```

训练：

```text
unitary synaptic strength
time constant
resting potential
neuronal gain
decoder
```

即：

$$
\boxed{
\text{freeze anatomy}
+
\text{learn physiology}

这实际上提出了一个非常有意思的问题：

# 20. Connectome 作为 Message-Passing Graph

还可以将每个 neuron 看成 graph node。

每个节点有 hidden state：

$$
H_i^t
$$

每一步首先收集 incoming messages：

$$
M_i^t
=
\sum_{j\rightarrow i}
W_{ji}H_j^t
$$

再进行 node update：

$$
H_i^{t+1}
=
f_\theta(
H_i^t,
M_i^t,
\eta_i
)
$$

其中：

$$
\eta_i
$$

可以表示：

- neuron identity；
- cell class；
- neurotransmitter；
- intrinsic dynamics；
- anatomical compartment。

这实际上就是：

```text
biological connectome
        ↓
directed GNN
        ↓
recurrent message passing
```

如果连接身体：

```text
sensory observation
        ↓
afferent neurons
        ↓
connectome message passing
        ↓
efferent / descending neurons
        ↓
motor decoder
        ↓
physics simulator
```

就可以进一步使用：

```text
imitation learning
+
reinforcement learning
```

训练动作。

# 21. Brian2 版本：直接模拟 Whole-Brain SNN

如果目标是尽量接近 Shiu 等人的 whole-brain simulation，Brian2 比 PyTorch RNN 更自然。

LIF dynamics 可以写成：

$$
\tau_m
\frac{dV_i}{dt}
=
-
(V_i-V_{rest})
+
g_i
$$

synaptic current：

$$
\tau_{syn}
\frac{dg_i}{dt}
=
-g_i
$$

presynaptic spike 到达时：

$$
g_j
\leftarrow
g_j
+
W_{ij}
$$

基本实现：

```python
from brian2 import *


N = len(nodes)


Vrest = -52 * mV
Vreset = -52 * mV
Vth = -45 * mV

tau_m = 20 * ms
tau_syn = 5 * ms


eqs = """

dv/dt = (
    g
    -
    (v - Vrest)
) / tau_m : volt (unless refractory)

dg/dt = (
    -g
) / tau_syn : volt

"""


G = NeuronGroup(
    N,
    eqs,
    threshold="v > Vth",
    reset="""
    v = Vreset
    g = 0*mV
    """,
    refractory=2.2 * ms,
    method="euler",
)


G.v = Vrest


S = Synapses(
    G,
    G,
    model="""
    w : volt
    """,
    on_pre="""
    g_post += w
    """,
    delay=1.8 * ms,
)


src_numpy = src.cpu().numpy()
dst_numpy = dst.cpu().numpy()
synapse_count_numpy = edges["syn_count"].to_numpy(dtype=np.float32)
sign_numpy = edges["sign"].to_numpy(dtype=np.float32)

S.connect(
    i=src_numpy,
    j=dst_numpy,
)

# Shiu et al. (2024) 的默认单突触权重尺度；不是普适生理常数。
S.w = (
    sign_numpy
    * synapse_count_numpy
    * 0.275
    * mV
)
```

整个流程为：

```text
FlyWire connectome
        ↓
NeuronGroup
        ↓
Synapses
        ↓
LIF whole-brain network
        ↓
spike propagation
```

\tau_i=\tau

$$
\tau_i
=
\tau_{T_i}
$$

以及：

$$
b_i=b_{T_i}
$$

$$
f_i=f_{T_i}
$$

其中：

$$

$$

表示神经元 cell type。

于是：

```text

```

可以使用一种 dynamics；

```text
projection neurons
```

使用另一种；

```text
descending neurons
```

再使用另一种。

# 23. Artificial Neuron 本身可以是一个小网络

进一步可以将：

$$
h_i^{t+1}
=
f(
h_i^t,
I_i^t
)
$$

改成：

$$
h_i^{t+1}
=
F_{\theta_{T_i}}
(
h_i^t,
I_i^t,
m_i^t
)
$$

例如：

```python
class BiologicalCell(nn.Module):

    def __init__(
        self,
        hidden_dim
    ):

        super().__init__()

        self.cell = nn.GRUCell(
            input_size=2,
            hidden_size=hidden_dim
        )

    def forward(
        self,
        synaptic_input,
        modulatory_input,
        state
    ):

        x = torch.stack(
            [
                synaptic_input,
                modulatory_input
            ],
            dim=-1
        )

        return self.cell(
            x,
            state
        )
```

于是：

```text
one biological neuron
```

不再对应：

```text
one scalar activation
```

而是：

```text
one small dynamical computation unit
```

# 24. 增加 Neuromodulatory State

网络状态可以扩展为：

$$
h(t)
$$

以及：

$$
m_{DA}(t),
m_{5HT}(t),
m_{OA}(t)
$$

这些调制变量可以改变：

- neuron gain；
- synaptic gain；
- membrane time constant；
- plasticity rate；
- decision threshold。

例如：

$$
\tau_i^{eff}
=
\tau_i
\left[
1+\gamma_i m(t)
\right]
$$

或者：

$$
W_{ij}^{eff}
=
W_{ij}
\left[
1+\beta_{ij}m(t)
\right]
$$

这样网络拥有类似：

```text
context
arousal
reward
motivation
```

的动态状态。

# 25. Local Plasticity

一个 biological-inspired 学习规则可以写成：

$$
e_{ij}(t+1)
=
\lambda
e_{ij}(t)
+
h_i(t)
h_j(t)
$$

然后：

$$
\Delta W_{ij}
=
\eta
R(t)
e_{ij}(t)
$$

其中：

- \(e_{ij}\)：eligibility trace；
- \(R(t)\)：reward 或 dopamine-like signal。

这意味着：

```text
local pre/post activity
        ↓
eligibility
        ↓
global reward modulation
        ↓
weight update
```

相较于：

```text
loss
↓
backprop through entire brain
↓
update every synapse
```

这种机制更加接近生物 learning。

# 26. 真正值得从果蝇脑提炼的 ANN 设计原则

目标并不应该只是：

> 把果蝇脑完整复制到 GPU。

更重要的是提炼它为什么可能是一种优秀 computational architecture。

---

## 26.1 Sparse Connectivity

真实大脑不是 dense layer。

更像：

$$
E\ll N^2
$$

所以：

```text
sparse recurrent graph
```

可能比：

```text
fully-connected recurrent matrix
```

更符合高效计算。

---

## 26.2 Topology 本身就是 Inductive Bias

传统神经网络：

```text
architecture relatively generic
+
knowledge mostly stored in weights
```

Connectome-inspired 网络：

```text
knowledge partly stored in topology
+
knowledge partly stored in dynamics
+
knowledge partly stored in weights
```

也就是说：

> “谁能够连接谁”本身就是计算结构的一部分。

# 27. 参数共享应该根据 Biology

CNN 的参数共享：

```text

```

Transformer 的参数共享：

```text

```

共享生理参数。

例如：

$$

$$

而不是每一条 PN→KC synapse 都是完全独立的参数。

# 38. 一个可能的下一代 Connectome ANN 架构

综合上述思想，可以定义：

$$
\boxed{
\mathcal{N}
=
(
G,
F_\theta,
M_\phi,
P_\psi
)
}
$$

其中：

- \(G\)：真实 Connectome topology；
- \(F_\theta\)：cell-type-specific neural dynamics；
- \(M_\phi\)：neuromodulatory dynamics；
- \(P_\psi\)：plasticity mechanism。

单个 neuron：

$$
h_i^{t+1}
=
F_{\theta_{T_i}}
\left(
h_i^t,
\sum_jW_{ji}^{eff}(t)h_j^t,
x_i^t,
m_i^t
\right)
$$

其中：

$$
W_{ji}^{eff}(t)
=
s_j
f(c_{ji})
\alpha_{T_j,T_i}
\left(
1+\beta_{ji}m(t)
\right)
$$

plasticity：

$$
e_{ji}^{t+1}
=
\lambda e_{ji}^t
+
\Phi(
h_j^t,
h_i^t
)
$$

$$
\Delta W_{ji}
=
\eta
m(t)
e_{ji}(t)
$$

最终得到：

```text
Connectome topology
        +
cell-type dynamics
        +
neuromodulation
        +
local plasticity
        +
task optimization
        +
embodiment
```

# 40. 总结

真正有潜力的方向不是单纯：

> **“复制一张果蝇脑连接图。”**

而是将 Connectome 看作一种新的 neural architecture prior。

即：

$$
\boxed{
\text{Anatomy}
\rightarrow
\text{Architecture}
}
$$

$$
\boxed{
\text{Neurotransmitter}
\rightarrow
\text{Sign Constraint}
}
$$

$$
\boxed{
\text{Synapse Count}
\rightarrow
\text{Structural Strength Prior}
}
$$

$$
\boxed{
\text{Cell Type}
\rightarrow
\text{Shared Neural Dynamics}
}
$$

$$
\boxed{
\text{Neuromodulator}
\rightarrow
\text{Context / Reward / Plasticity}
}
$$

$$
\boxed{
\text{Sensory-Motor Circuit}
\rightarrow
\text{Embodied Policy Architecture}
}
$$

因此，一个真正值得研究的下一代 ANN 可能不再只是：

```text
Dense Layer
+
ReLU
+
Backprop
```

而更接近：

```text
Sparse biological topology

+ signed connectivity

+ heterogeneous neural dynamics

+ recurrent continuous-time computation

+ neuromodulatory state

+ local plasticity

+ global task optimization

+ embodied interaction
```

最值得进一步研究的问题最终是：

$$
\boxed{
\text{真实神经系统的 wiring principles，
能否成为比人工设计网络拓扑更强的 inductive bias？}
}
$$

以及：

$$
\boxed{
\text{哪些 biological constraints 必须保留，
哪些可以交给 gradient descent 自由学习？}
}
$$

这可能比单纯“模拟果蝇全脑”更接近 Connectomics 对下一代人工智能真正长期的价值。
