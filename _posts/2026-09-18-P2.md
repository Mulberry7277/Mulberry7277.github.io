在上一篇笔记中，我们用集合论的语言定义了“事件”和“概率”。但对于数学分析来说，集合太抽象了，无法进行加减乘除、求导和积分。为了把概率论纳入微积分的强大计算框架中，我们需要进行一次决定性的概念升级——**将抽象的事件映射到实数轴上**。完成这个伟大任务的桥梁，就是“随机变量”。

## §2.1 随机变量的概念 (Concept of Random Variable)

**定义**：设随机试验的样本空间为 $\Omega$。如果对于 $\Omega$ 中的每一个样本点 $\omega$，都有一个唯一的实数 $X(\omega)$ 与之对应，那么就称这个定义在样本空间 $\Omega$ 上的**实值函数** $X = X(\omega)$ 为**随机变量 (Random Variable)**。

> **深度理解**：
> 1.  随机变量本质上**不是变量，而是一个函数**！它的定义域是样本空间，值域是实数集。
> 2.  **意义**：比如掷硬币，结果是 {正面, 反面}。我们规定 $X(\text{正面}) = 1$，$X(\text{反面}) = 0$。这样，我们就把抽象的物理结果，变成了实实在在的数字。从此，研究事件发生的概率，就变成了研究变量取值的概率。

按照变量取值的特征，随机变量主要分为两大类：**离散型**和**连续型**。

---

## §2.2 累积分布函数 (Cumulative Distribution Function, CDF)

在分门别类之前，我们需要一个能够**统领全局**（无论离散还是连续都能用）的通用工具，这就是分布函数。

**定义**：设 $X$ 为一个随机变量，对任意实数 $x$，定义函数：
$$F(x) = P(X \le x)$$
称为随机变量 $X$ 的**分布函数**。它表示变量取值落在区间 $(-\infty, x]$ 上的概率。

**分布函数的四大基本性质**：
1.  **有界性**：$0 \le F(x) \le 1$。且 $F(-\infty) = 0$，$F(+\infty) = 1$。
2.  **单调性**：$F(x)$ 是一个**单调不减**函数。即若 $x_1 < x_2$，必有 $F(x_1) \le F(x_2)$。
3.  **右连续性**：$F(x+0) = F(x)$。（这与我们定义的是 $X \le x$ 有关）。
4.  **区间概率计算**：$P(a < X \le b) = F(b) - F(a)$。

## §2.3 离散型随机变量及其分布律

**特征**：随机变量的取值是有限个或可列无限个（比如抛硬币的次数、某个时间段内的电话呼入量）。

对于离散型随机变量，分布函数呈“阶梯状”。我们通常直接用**分布律 (Probability Mass Function, PMF)** 来描述它：
$$P(X = x_k) = p_k, \quad k = 1, 2, \dots$$
且必须满足：$p_k \ge 0$ 以及归一性 $\sum p_k = 1$。

### 常见的离散型分布：
1.  **0-1 分布 (伯努利分布, Bernoulli Distribution)**
    *   只有两种结果，取值为 0 或 1。
    *   $P(X=1) = p, \ P(X=0) = 1-p$。
2.  **二项分布 (Binomial Distribution, 记为 $X \sim B(n, p)$)**
    *   进行了 $n$ 次独立的伯努利试验，每次成功概率为 $p$。$X$ 表示成功的总次数。
    *   $P(X=k) = C_n^k p^k (1-p)^{n-k}, \quad k = 0, 1, \dots, n$
3.  **泊松分布 (Poisson Distribution, 记为 $X \sim P(\lambda)$)**
    *   描述在一定时间或空间内，**稀有事件**发生的次数（如放射性衰变、车祸次数）。
    *   $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \dots$
    *   *泊松定理：当 $n$ 很大，$p$ 很小，且 $np = \lambda$（常数）时，二项分布可以用泊松分布来极好地近似。*

## §2.4 连续型随机变量及其概率密度函数

**特征**：随机变量可以在某个区间内取**任何实数值**（比如人的身高、灯泡的寿命）。此时，它有不可数无限多个取值。

> **⚠️ 一个反直觉的极重要结论**：
> 对于连续型随机变量，它取任何一个特定点 $a$ 的概率**恒为 0**，即 $P(X=a) = 0$。
> （因为线段上有无限个点，落在一个没有宽度的几何点上的概率极限为零）。因此，对于连续变量讨论 $X=a$ 是没有意义的，我们只能讨论它**落在一个区间里的概率**。也正因为如此，$P(a < X < b) = P(a \le X \le b)$，边界包含与否不影响概率计算。

为了描述连续型随机变量落在各个区间的可能性大小，我们引入**概率密度函数 (Probability Density Function, PDF)**，记为 $f(x)$。

**定义**：如果对于分布函数 $F(x)$，存在一个非负函数 $f(x)$，使得对于任意实数 $x$，都有：
$$F(x) = \int_{-\infty}^x f(t) dt$$
则称 $X$ 为连续型随机变量，$f(x)$ 为其概率密度函数。

**$f(x)$ 的三大性质**：
1.  **非负性**：$f(x) \ge 0$。（注意：$f(x)$ 本身不是概率，它的值可以大于 1，但它在某个区间的积分才是概率，且积分必须小于等于 1）。
2.  **规范性 (总面积为1)**：$\int_{-\infty}^{+\infty} f(x) dx = 1$。
3.  **区间概率**：$P(a < X \le b) = \int_a^b f(x) dx$。（即密度曲线在区间 $[a,b]$ 上与 x 轴围成的面积）。

---

## §2.5 常见的连续型分布

### 1. 均匀分布 (Uniform Distribution, 记为 $X \sim U(a, b)$)
在区间 $(a, b)$ 内，变量落在等长度子区间的概率是相等的。
$$f(x) = \begin{cases} \frac{1}{b-a}, & a < x < b \\ 0, & \text{其他} \end{cases}$$

### 2. 指数分布 (Exponential Distribution, 记为 $X \sim Exp(\lambda)$)
常用于描述寿命、排队等待时间等。
$$f(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \\ 0, & x \le 0 \end{cases} \quad (\lambda > 0)$$
*   **神奇的“无记忆性”**：已知元件已经工作了 $s$ 小时，它还能再工作 $t$ 小时的概率，与一个全新的元件工作 $t$ 小时的概率完全相同！即 $P(X > s+t \mid X > s) = P(X > t)$。

### 3. ★ 正态分布 / 高斯分布 (Normal / Gaussian Distribution, 记为 $X \sim N(\mu, \sigma^2)$)
这是概率论与数理统计中**最伟大的分布**，自然界中绝大多数宏观连续现象都服从正态分布。
其概率密度函数呈现完美的“钟形曲线”：
$$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \quad -\infty < x < +\infty$$
*   **$\mu$ (位置参数)**：决定了曲线对称轴的位置，也是变量的最可能取值中心。
*   **$\sigma$ (形状参数)**：决定了曲线的胖瘦。$\sigma$ 越大，曲线越矮胖（数据越分散）；$\sigma$ 越小，曲线越高瘦（数据越集中）。

**标准正态分布 $N(0, 1)$**：
当 $\mu = 0, \sigma = 1$ 时，密度函数简化为著名的 $\varphi(x)$：
$$\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}$$
*   **标准化操作**：任何一般正态分布 $X \sim N(\mu, \sigma^2)$，都可以通过线性变换 $Z = \frac{X - \mu}{\sigma}$ 转化为标准正态分布 $Z \sim N(0, 1)$。这使得我们只需要一张“标准正态分布表”，就能计算所有正态分布的概率。
*   **$3\sigma$ 法则**：正态变量落在区间 $(\mu-3\sigma, \mu+3\sigma)$ 内的概率高达 $99.73\%$。在实际应用中，落在该区间之外的事件常被视为“小概率事件”。
